## What this project is
One or two sentences: what it does and who uses it.

## Commands
- Run tests: `python -m pytest`
- Run the app: `python main.py`

## Rules
- Write a failing test before writing the code.
- Keep changes small. One task per commit.
- Do not add dependencies without asking.
- Never commit secrets or `.env` files.

## Style
- Python 3.10+, standard library first.
- Functions short and named for what they do.
- Add a docstring to every public function.

## Before you say "done"
- All tests pass.
- Ran `/code-review` on the diff.
